# Project starter

Create a project folder, initialize git, and keep the first docs small.

## Always

- `README.md` — what it is, how to run it, and how to know it works.
- A one-line pointer to `C:\Users\ANISH\Documents\ai-playbook\INDEX.md` in the project's agent file (`AGENTS.md`, `CLAUDE.md`, or the equivalent). Point. Do not paste the vault in.

## When the work has phases

Copy `C:\Users\ANISH\Documents\ai-playbook\roadmaps\TEMPLATE.md` to `roadmaps\ROADMAP.md` in the project when any of these is true:

- The work will take more than one session.
- More than one model will touch it.
- There is a real now / next / later split.

## Only when a choice is expensive to reverse

- `DECISIONS.md` — the decision, the reason, and the date. Skip it for ordinary implementation choices.

## Then

Open `skill-catalog.md` and read the one skill set that matches the first task. For a codebase question about an existing repo, the graphify skill is `C:\Users\ANISH\.claude\skills\graphify\SKILL.md`.
