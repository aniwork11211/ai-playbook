# Creator toolkit

Four sites for design, motion, launch video, and pitch decks. The "vibe coded" cover and the four-tool tray are this same set.

**Next:** Godly

A future session opens this file from `C:\Users\ANISH\Documents\ai-playbook\LIBRARY.md` and uses one site for the job in front of it.

- [ ] **Godly** — `godly.design`. Curated websites, web apps, and UI. Use it before inventing a layout.
- [ ] **transitions.dev** — copy-paste UI animations. Tailwind CSS, Framer Motion, and CSS. Open source.
- [ ] **Animos** — `animos.com`. Turn app screenshots into a launch video in the browser.
- [ ] **Deck.Gallery** — real pitch decks from companies such as OpenAI, Perplexity, Stripe, Notion, Figma, and Linear. Use a layout, do not copy the company's story.

Order when shipping a product surface: Godly for the look, transitions.dev for the motion, Animos for the launch video, Deck.Gallery when the work is a pitch.
