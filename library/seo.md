# SEO

Six jobs. When the work is SEO, open this file from `C:\Users\ANISH\Documents\ai-playbook\LIBRARY.md` and use the one job the task needs.

**Next:** Keyword research

## Keyword research

Find the words customers type and which deserve a page.

- [ ] List problems in the customer's words
- [ ] Start with a broad seed phrase
- [ ] Use one keyword tool
- [ ] Check whether results teach, compare, or sell
- [ ] Judge volume, difficulty, and trend
- [ ] Group similar keywords onto one page

## On-page SEO

Each page answers one search.

- [ ] Title matches the search phrasing and can show in full
- [ ] Meta description says why this result wins
- [ ] Headings are real reader questions
- [ ] The first sentence answers the heading
- [ ] Real photos with alt text
- [ ] Internal links whose anchor text matches the target title

## Technical SEO

Google and AI crawlers can reach, read, and index every page.

- [ ] Important pages within three clicks of home
- [ ] Words in raw HTML, because most AI crawlers do not run JavaScript
- [ ] Search Console Pages report for skipped URLs
- [ ] Main content loads first
- [ ] Usable one-handed on a phone
- [ ] XML sitemap of only the pages you want ranked, submitted to Google and Bing

## Content

Publish what the pages above you do not say.

- [ ] One main search per page
- [ ] Answer first
- [ ] Add original data, photos, or results
- [ ] Answer the follow-up questions
- [ ] Update stats and dates
- [ ] Put a real author name on every article

## Off-page SEO

Other sites, reviews, and forums talk about you.

- [ ] Links from sites customers already read
- [ ] Data or stories journalists want
- [ ] Brand mentions even without a link
- [ ] Reviews on Google and trusted industry sites
- [ ] Identical name, address, and phone everywhere
- [ ] Answer questions on the forums customers use

## Analytics

Track what changed, then do more of what worked.

- [ ] Search Console for queries, clicks, and pages
- [ ] GA4 for what visitors do and which pages convert
- [ ] Track the top 20 keywords weekly
- [ ] Measure referrals from ChatGPT, Perplexity, and Gemini
- [ ] Note what changed and when
- [ ] Monthly review, fix the biggest slip first
