# 3D libraries for vibecoders

Four tools. The cover says they are worth knowing for vibecoding and 3D. No links were printed on the slides.

Use this file when the work is one of these four. Open it from `C:\Users\ANISH\Documents\ai-playbook\LIBRARY.md` and use only the tool the task needs. Three.js as a Claude skill stays in `C:\Users\ANISH\Documents\ai-playbook\library\claude-animation-skills.md`.

## 1. Aceternity UI

React and Tailwind components with polished motion and 3D effects. Tags on the slide: React, Tailwind, motion.

The site screen calls it a collection of production-ready components built with React, Tailwind CSS, and Framer Motion. A badge says v2.0 is here. The same screen shows 24.4K with no readable label next to the number.

Three cards on the screen: interactive components, animations built with Framer Motion, and copy-paste components that are ready to ship.

## 2. Canvas UI

Canvas-powered effects for WebGL and WebGPU interfaces. Tags: WebGL, WebGPU, HTML-in-canvas.

The site screen calls it a library of HTML-in-canvas components: customizable, performant, built with WebGL and WebGPU, and usable with any framework. A badge says the Ripple component is live. Named effects on the screen: Aurora, Fluid, Glass, Ripple, Spotlight.

## 3. vgpu

By Vercel Labs. A WebGPU library for modern, agent-assisted graphics. Tags: WebGPU, WGSL, agents.

The site screen calls it a TypeScript framework for graphics with WebGPU, with more control for advanced use cases, and designed to be LLM friendly. Named examples: raymarched reflections (SDF raymarching with dynamic reflections and soft shadows), a particle ocean (interactive particle simulation with fluid dynamics), instanced particles (high-performance instanced rendering with custom shaders), and 3D gaussian splatting in the browser. The slide spells gaussian in lowercase.

## 4. Spline

Create interactive 3D scenes and bring them to the web. Tags: React, R3F, Drei, Three.js. The slide’s path is design, then 3D, then interaction.

The site screen calls it a design tool for interactive 3D experiences on the web. Build with a team, add interactivity, and export to React, Three.js, or a link. The screen says it is free, no credit card is required, and it starts in the browser.

Four actions on the screen: design in 3D (model, animate, and iterate in real time), add interactivity with events, collaborate in real time, and export to React, Three.js, or a shared link.
