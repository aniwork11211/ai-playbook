# 20 repos for a motion design studio

Source: @prananjay.ai. Launch videos, product demos, and animated explainers, built with Claude Code. The cover names Opus 5.5.

Use this file when the work is picking a repo for a launch video, a demo, or web motion. Open it from `C:\Users\ANISH\Documents\ai-playbook\LIBRARY.md` and use only the group the task needs.

Claude writes the code. Skills guide the timing and the visual direction. Remotion or HyperFrames renders the video. Some repos are for web animation instead. Pick by the output.

## Motion starters

1. **claude-motion** — toolkit. Motion direction, frame review, and code-generated sound. `github.com/whaleyxbt/claude-motion`
2. **claude-motion-design** — skill. HTML video workflow using Playwright and FFmpeg. `github.com/howseen-ai/claude-motion-design`
3. **motion-graphics-skills** — skill pack. 13 skills for launch videos, charts, and motion graphics. `github.com/charlie947/motion-graphics-skills`

## Editing and craft

4. **claude-remotion-skill** — skill. Remotion video workflow for captions, B-roll, and sound. `github.com/haidrrry/claude-remotion-skill`
5. **klik-anim-skill-creation** — skill pack. Animation, camera, and production guidance for Remotion. `github.com/t3knobox/klik-anim-skill-creation`
6. **hyperframes-motion-reel-skill** — skill. Beat-synced HyperFrames showreels with coded sound. `github.com/Sunwood-ai-labs/hyperframes-motion-reel-skill`

## Launch and animation

7. **product-launch-motion** — skill. Launch films with voiceover, camera moves, and audio sync. `github.com/AbubakrChan/product-launch-motion`
8. **animate** — skill. Short Canvas animations, storyboarded before rendering. `github.com/cth9191/animate`
9. **motion-design-skills** — skill pack. Skills for timing, color, composition, logos, and video. `github.com/iart-ai/motion-design-skills`

## Kits and rendering

10. **hyperframes-student-kit** — editing kit. Editing workflows plus 406 draft motion-graphics cards. `github.com/nateherkai/hyperframes-student-kit`
11. **hyperframes** — video tool. Turns HTML, CSS, and timed animation into MP4 video. `github.com/heygen-com/hyperframes`
12. **remotion** — video tool. Builds and renders videos with React components. `github.com/remotion-dev/remotion`

## Code and craft

13. **Remotion Agent Skills** — skill pack. Official guidance for agents working in Remotion. `github.com/remotion-dev/skills`
14. **GSAP** — library. JavaScript timelines for web and coded video animation. `github.com/greensock/GSAP`
15. **motion-design-skill** — skill. Timing and choreography principles across animation tools. `github.com/LottieFiles/motion-design-skill`

## Maps and web motion

16. **awesome-motion-design-agent-skills** — directory. Curated motion resources plus installable agent skills. `github.com/frankxai/awesome-motion-design-agent-skills`
17. **motion-graphics** — skill pack. Motion B-roll timed to a supplied video and transcript. `github.com/Barty-Bart/motion-graphics`
18. **motion-dev-animations-skill** — web skill. Motion.dev patterns for scroll, springs, and interactive UI. `github.com/199-biotechnologies/motion-dev-animations-skill`

## Web animation

19. **motion** — web library. Animation library for JavaScript, React, and Vue. `github.com/motiondivision/motion`
20. **lottie-web** — web player. Plays Lottie JSON animations in the browser. `github.com/airbnb/lottie-web`
