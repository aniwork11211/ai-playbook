# Five Claude tools for paid websites

Source: @sebastianhardy_. The cover says Claude can make you $15K a week building websites, and to take these five free tools. The five price labels add up to $15,000. Those figures are the post’s labels for what a client pays, not a verified rate.

Use this file when the work is picking one of these five. Open it from `C:\Users\ANISH\Documents\ai-playbook\LIBRARY.md` and use only the tool the task needs. The numbered slides in the set are 02 through 06 of 7. Slides 01 and 07 were not attached. The five tools themselves are all here. No repo path is printed. How to build a site that does not look generic stays in `C:\Users\ANISH\Documents\ai-playbook\library\vibe-coded-site.md`.

1. **The $5,000 designer.** A design skill for sites built with AI. The slide says that without it Claude gives you the same purple gradient every AI site has, and that with it the sites are the kind clients pay $5,000 for. The slide says 95K GitHub stars. It works in Claude Code and Codex.
2. **The $3,000 redesign.** A design skill with 23 commands. Click a part of the live site, say what feels off, and it rewrites that part in place. Audit, layout, type, and polish come from one install. The slide says 80K GitHub stars. The screen on the slide names Impeccable, and mentions a CLI and a Chrome extension. The installed copy of that skill is at `C:\Users\ANISH\.claude\skills\impeccable\SKILL.md`.
3. **The $2,000 animator.** A motion skill for animations and easing. Toasts, drawers, and menus get the smooth, springy motion the slide associates with expensive product sites. The slide says 45.6K GitHub stars. Focus on the slide: motion, easing.
4. **The $4,000 mockups.** The official Figma connector, by Figma. Claude pushes each screen it builds into Figma as an editable frame, so a client comments on the design instead of a screenshot. The graphic says “Claude Code to Figma.” It works with Claude Code.
5. **The $1,000 QA tester.** A browser connector that tests the site itself. Claude opens the site in a real browser, logs in, clicks through every page, and fixes what breaks before you see it.
