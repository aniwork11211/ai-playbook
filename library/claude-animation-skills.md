# Claude Code skills for animation

Source: @bitbybit. Five free public skills. The cover says they install in one command. The command itself was not in the set. The post says a skill is not a prompt: install it once and Claude keeps the capability.

Use this file when the work is choosing one of these five for a page that moves. Open it from `C:\Users\ANISH\Documents\ai-playbook\LIBRARY.md` and use only the skill the task needs. The longer motion-repo list, including GSAP and the Lottie skill as libraries, stays in `C:\Users\ANISH\Documents\ai-playbook\library\motion-design-repos.md`.

Start with Design DNA. The post says it changes how everything else looks, and the difference shows immediately. They stack: Design DNA sets the direction, GSAP and Motion Design handle how it moves, Three.js adds depth, and Genjutsu does the final pass. The post says nothing here is paid or sponsored.

1. **Three.js.** `CloudAI-X/threejs-skills`. Interactive 3D scenes, camera controls, GLTF models, lighting, and particles. The line on the post: it turns a flat page into something you can move around in. The slide also lists lighting setup.
2. **GSAP.** `greensock/gsap-skills`. The official GreenSock skill. Timeline animation, ScrollTrigger, text reveals, and React integration.
3. **Design DNA.** `zanwei/design-dna`. Point it at a site and it extracts the design as machine-readable tokens: color palette, typography, layout, and spacing. The slide also lists reverse-engineering a design and copying a UI style.
4. **Motion Design.** `lottiefiles/motion-design-skill`. Built by the LottieFiles team. Lottie and SVG animation, keyframes, interactive states, and export to JSON or dotLottie. The slide also lists an AI motion workflow.
5. **Genjutsu.** `AThevon/genjutsu`. Creative direction and the finishing pass. The slide lists award-winning UI, a modern layout, premium animation, and visual polish.
