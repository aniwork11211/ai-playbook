The stack named in section 1 is HTML, CSS, and JavaScript, then React, then Node.js with Express, then MongoDB or PostgreSQL.

## 1. Introduction

- How frontend, backend, databases, APIs, and deployment work together.
- Browsers, servers, HTTP/HTTPS, domains, hosting, and web applications.
- Pick the beginner stack above.

## 2. HTML

- Headings, paragraphs, links, images, lists, tables, and forms.
- Semantic elements: header, nav, main, section, article, and footer.
- Form inputs, labels, validation, dropdowns, checkboxes, and radio buttons.
- Accessibility: semantic structure, labels, alt text, and keyboard navigation.
- Projects: a personal portfolio, a registration form, a landing page, and a blog layout.

## 3. CSS

- Selectors, colors, fonts, units, backgrounds, borders, and spacing.
- The box model: margin, padding, border, width, and height.
- Flexbox and CSS Grid.
- Sites that work on mobile, tablet, and desktop.
- Animations, transitions, positioning, pseudo-elements, and media queries.
- Practice by recreating popular websites.

## 4. JavaScript

- Variables, data types, operators, conditions, loops, and functions.
- Arrays, objects, strings, sets, and maps.
- Destructuring, spread and rest, template literals, modules, and arrow functions.
- How JavaScript interacts with HTML and CSS.
- Event listeners, event bubbling, and form handling.
- Callbacks, Promises, async/await, and fetch.
- Closures, scope, hoisting, this, prototypes, and error handling.

## 5. Git and GitHub

- init, add, commit, status, log, and clone.
- Create, merge, and manage branches.
- Push and pull with GitHub.
- Pull requests, code reviews, issues, and merge conflicts.
- Meaningful commits and a clean repository.
- Keep the best projects public on GitHub.

## 6. Frontend development

- Start with React.
- Components, JSX, props, state, and events.
- useState, useEffect, useContext, useRef, and custom hooks.
- React Router and multi-page navigation.
- Connect the frontend to backend APIs.
- Context API first, then Redux Toolkit or another modern state library.
- Responsive design and component-based UI.

## 7. Backend development

- Node.js with Express.
- Modules, npm, file handling, environment variables, and asynchronous programming.
- Routes, controllers, middleware, request and response handling, and error handling.
- GET, POST, PUT/PATCH, and DELETE.
- Validate incoming data and handle errors.
- Authentication, authorization, password hashing, CORS, rate limiting, and common web vulnerabilities.

## 8. Databases

- Tables and collections, records and documents, relationships, indexes, and transactions.
- PostgreSQL or MySQL.
- SELECT, INSERT, UPDATE, DELETE, JOIN, GROUP BY, and aggregate functions.
- Primary keys, foreign keys, normalization, and relationships.
- MongoDB and document databases.
- Connect the backend with a driver or an ORM/ODM.

## 9. Authentication and authorization

- Signup with secure password handling.
- Secure login and logout.
- Hashing and safe credential storage.
- Cookies, sessions, JWTs, access tokens, and refresh tokens.
- Roles such as user, moderator, and admin.
- Restrict pages and APIs by authentication and permissions.

## 10. APIs and advanced backend

- Clean, scalable REST APIs.
- Document endpoints and request and response formats.
- Third-party APIs such as payment, maps, email, or AI.
- Image and document uploads.
- Why caching is useful, and the basics of Redis.
- WebSockets for chat, notifications, and live updates.
- Queues and asynchronous work for tasks that do not need to happen immediately.

## 11. Testing and code quality

- Unit tests for individual functions and components.
- Integration tests for how parts work together.
- API tests with a tool such as Postman.
- The basics of testing React components.
- Clean-code principles and consistent naming.
- Read errors, use browser developer tools, and troubleshoot systematically.

## 12. Deployment and DevOps basics

- Keep secrets and configuration in environment variables, outside the source.
- Production builds and configuration.
- Deploy the frontend on a suitable host.
- Deploy the API and connect it to the production database.
- Domains, DNS, SSL/TLS, and HTTPS.
- CI/CD: test and deploy automatically after changes.
- Containers and Dockerfiles, at a beginner level.
- AWS, Azure, or Google Cloud, at a beginner level.

## 13. System design basics

- How frontend, backend, database, and external services communicate.
- Vertical and horizontal scaling.
- Where caching is used, and why.
- Load balancing.
- Indexing, replication, and basic database optimization.
- High-level design of a URL shortener, a chat application, an e-commerce platform, and a social network.

## 14. Real-world projects

- Beginner: portfolio website, to-do app, weather app, calculator, blog.
- Intermediate: expense tracker, job portal, e-commerce website, quiz platform, URL shortener.
- Advanced: real-time chat, LMS, food-delivery platform, social media application, collaborative project-management tool.
- Capstone: one complete application with authentication, a database, a REST API, a frontend, and deployment.
- Quality means responsive UI, clean architecture, error handling, security, documentation, and deployment, not features alone.

## 15. Interview preparation

- HTML and CSS: semantic HTML, responsive design, Flexbox, and Grid.
- JavaScript: closures, promises, async/await, the DOM, the event loop, and ES6+.
- React: components, props, state, hooks, rendering, and performance.
- Backend: REST APIs, middleware, authentication, HTTP methods, and error handling.
- Database: SQL queries, joins, indexing, normalization, and transactions.
- DSA: arrays, strings, linked lists, stacks, queues, trees, hashing, sorting, and searching.
- Projects: be ready to explain the architecture, the technical decisions, the challenges, and how you solved them.

## Order and beginner stack

HTML, CSS, JavaScript, Git/GitHub, React, Node.js, Express, REST APIs, SQL/NoSQL, authentication, testing, deployment, Docker/cloud, system design, real-world projects, DSA, interviews.

Beginner stack printed at the end: HTML, CSS, JavaScript, and React on the frontend. Node.js and Express on the backend. PostgreSQL and MongoDB. Git and GitHub. Postman for API testing. Any beginner-friendly host for frontend and backend. AWS, Azure, or GCP at a basic level.
