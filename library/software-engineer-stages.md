# Modern software engineer roadmap

Ten stages. Most people stop at stage 4.

Use this file when the work is judging how far a software path has gone. Open it from `C:\Users\ANISH\Documents\ai-playbook\LIBRARY.md` and use only these stages. The longer study paths stay in their own files.

1. Learn coding.
2. Learn Git.
3. Learn databases.
4. Build APIs.
5. Learn cloud.
6. Understand system design.
7. Work with distributed systems.
8. Ship to production.
9. Lead projects.
10. Make business impact.
