# Japanese design principles

Seven principles. Use them when shaping a screen, a layout, or a visual direction. Tick one when you can apply it on purpose in a real interface.

**Next:** Kanso

## Principles

- [ ] **Kanso.** Simplicity. Remove what has no job. Nothing stays as decoration.
- [ ] **Fukinsei.** Balanced asymmetry. A controlled imbalance can feel more alive than a perfect mirror.
- [ ] **Shibui / Shibumi.** Understated beauty. Simple enough to rest, complex enough that you keep looking.
- [ ] **Shizen.** Naturalness. The result should not look forced. Human craft can be visible if it does not feel artificial.
- [ ] **Yugen.** Suggest more than you show. Leave room for what is not on the screen.
- [ ] **Datsuzoku.** Leave the usual formula. Break a habit when the conventional layout hides a better one.
- [ ] **Seijaku.** Organized calm. The screen can be busy and still feel quiet. Calm is arranged, not empty.

## How to use this

Pick one principle for the screen you are making. Name it in the layout decision. Do not apply all seven at once.
