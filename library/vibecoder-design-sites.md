# 5 websites every vibecoder should know

Stop guessing. Study real interfaces.

Use this file when the work is finding a real screen, flow, or landing page to study. Open it from `C:\Users\ANISH\Documents\ai-playbook\LIBRARY.md` and use the one site whose job matches the work.

- Mobbin — real UI/UX screen flows from real products. Study how popular apps solve navigation, onboarding, interaction, and product flows. Over 1,000 iOS and web apps, and 200 sites. Best for real UI/UX inspiration.
- Curated Design — startup websites and clean landing pages. A curated collection of startup-style marketing sites. Best for landing page inspiration.
- Saaspo — SaaS landing pages, pricing grids, feature sections, and reusable component patterns. Best for SaaS website inspiration.
- Dark Design — handpicked dark-mode websites built around contrast, spacing, hierarchy, and strong visual direction. Best for dark-mode UI inspiration.
- Pageflows — complete user flows from real products, from onboarding to checkout. Best for complete user flows. Study the journey, not a single screen.
